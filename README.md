# Cinewright

An open-source, agent-driven production framework for professional video: multi-scene productions with a cast of narrators and characters, a style system, and a built-in quality loop.

**Status:** design complete; implementation starting at v0.1. See `docs/HANDOFF.md`.

- `AGENTS.md` — contributor and coding-agent rules
- `docs/DESIGN_SPEC.md` — architecture and decision log
- `docs/V0_1_PLAN.md` — current milestone plan
